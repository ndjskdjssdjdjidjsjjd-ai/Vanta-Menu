# VantaMenu

A free and open-source mod menu for Geometry Dash, built with Geode

## Features

- **NoClip** 
- **Unlock Icons** 
- **Practice Music** 
- **Instant Complete** 
- **Safe Mode** 
- **Macro System** 
- **FPS / TPS Bypass** 
- **Speedhack**
- **And More...**

## How to Use

1. Press `Tab` in-game to open or close the menu.
2. Use the sidebar to navigate between **About**, **Main** (Cheats), and **Bot** (Macros)
3. Toggle your desired features
